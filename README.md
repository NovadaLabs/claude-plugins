# Novada — Claude Code plugins

Official [Novada](https://www.novada.com) marketplace for Claude Code.

## Install

```
/plugin marketplace add NovadaLabs/novada-claude-plugins
/plugin install novada@novada
export NOVADA_API_KEY=nvd_...
```

## Plugins

| Plugin | What it does |
|--------|--------------|
| **novada** | Web search, scraping, crawling, extraction, research & proxy via the Novada MCP server, + a routing skill. |

Get an API key at <https://dashboard.novada.com/overview/scraper/api-playground/>.
